# Mehdi Ghasemi

Senior Scientist–Mathematician — polynomial optimization, moment methods, and scientific ML in Python.

**Publications:** [Google Scholar](https://scholar.google.com/citations?user=1PlVtHsAAAAJ) (h-index 16 · 1,600+ citations)

## Libraries under active development

| Library | What it does |
|---|---|
| [Irene](https://github.com/mghasemi/Irene) | Toolkit for constrained polynomial optimization over commutative real algebras — SOS/SONC/moment-SDP hierarchies with SymEngine/SymPy backends, CVXPY/CVXOPT solver paths, and structural reductions (border basis, correlative sparsity, Newton-polytope pruning). |
| [SKSurrogate](https://github.com/mghasemi/sksurrogate) | Research-grade suite for surrogate-based optimization of expensive functions and AutoML pipeline search, scikit-learn style; includes a Hilbert-space regressor, dataset fingerprinting/schema validation, and a web UI with control-plane API. |

## Applied AI / LLM engineering

| Project | What it does |
|---|---|
| [TinyRAG](https://github.com/mghasemi/TinyRAG) | Self-hosted retrieval-augmented generation system for AI agents: FastAPI backend with a multi-collection ChromaDB vector store and SQLite/SQLAlchemy metadata, token-streamed QA over SSE with source attribution, runtime-switchable OpenAI-compatible LLM providers, drag-and-drop ingestion of `.txt`/`.md`/`.pdf`, and a React/TypeScript UI — all deployed via Docker Compose. Ships an MCP server so agents (Hermes, Claude, Cursor) can query document collections directly. |
